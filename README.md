# Lung Sound Classification

This repository contains MATLAB and Google Colab implementations for lung sound classification using
fluctuation-based dispersion entropy (FDispEn) features and Discrete Wavelet Transform (DWT).

## Dataset
The dataset used in this project is stored in `data99oke.mat` and consists of lung sound signals and their corresponding class labels.
The dataset is provided for academic and research purposes.

## Method
- Signal preprocessing and normalization  
- DWT decomposition using Daubechies 4 (db4) wavelet  
- Feature extraction using FDispEn (MATLAB)  
- Machine learning classification and evaluation (Google Colab)

## Models
- Support Vector Machine (SVM)  
- Multilayer Perceptron (MLP)  
- XGBoost  

## Tools
- MATLAB  
- Google Colab
