# Notebooks

This folder contains the source code used in this project.

## Files

1. `01_dwt_fdispen.m`
   - MATLAB implementation for lung sound preprocessing, Discrete Wavelet Transform (DWT), and Fluctuation-based Dispersion Entropy (FDispEn) feature extraction.

2. `02_ml_evaluation_dwt_fdispen.ipynb`
   - Google Colab notebook for machine learning model training and performance evaluation using the extracted features.

The notebooks are organized in the recommended execution order.
